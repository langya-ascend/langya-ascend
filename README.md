## What I'm Building

### SiteGO · Bring website Q&A into your workflow

SiteGO is being built to connect website Q&A to a unified API, with independent single-turn tasks, account scheduling, answer sources, and operator takeover for GEO evaluation and business integrations.

**Current status: product documentation and the roadmap are public; application source and container images are not yet released and remain in preparation.** The first public edition is planned around Doubao and Tencent Yuanbao. Supported features will follow version-specific acceptance evidence.

## How I Maintain Projects

- Start with a specific use case and keep documentation and screenshots aligned with actual behavior.
- Deliver small, clear improvements, separating implementation, verification, and release status.
- When a project is ready for public release, publish versions through **tags and releases**, with Chinese and English notes, upgrade guidance, and known limitations.
- Use reproducible feedback to improve projects and be direct about their scope and unfinished work.

Each project states its own license. SiteGO is planned as source-available software for noncommercial use; commercial use requires the copyright holder's prior written authorization. The final license included with a release will define its terms.
