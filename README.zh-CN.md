## 正在做什么

### SiteGO · 让网站问答进入你的工作流

SiteGO 正在围绕独立单轮任务、账号调度、回答信源和运维接管建设，将网站问答接入统一 API，服务 GEO 检测与业务集成。

**当前状态：产品文档与路线图已公开，应用源码与容器镜像尚未发布，正在准备中。** 首批公开版计划支持豆包和腾讯元宝，具体功能以版本验收记录为准。

## 我怎样维护项目

- 从具体使用场景出发，让文档、截图与实际能力一致。
- 持续发布小而明确的改进，分别记录开发完成、验证通过与正式发布。
- 项目准备好对外发布时，使用 **Tag + Release**，附带中英文更新说明、升级方式与已知限制。
- 用可复现的问题反馈推动改进，对适用范围和未完成事项保持坦诚。

每个项目分别说明使用许可。SiteGO 计划采用源码可见、限非商业用途的模式，商业使用须事先取得著作权人的书面授权；最终条款以正式版本随附许可为准。
