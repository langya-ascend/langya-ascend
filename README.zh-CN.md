# 你好，我是 Langya

[English](README.md) | [简体中文](README.zh-CN.md)

把真实需求做成实用工具，是我持续开发的方向。

我关注 AI 应用、网站自动化和开发者体验，希望把日常工作中反复遇到的问题，变成易用、可靠、值得长期维护的软件。

## 当前项目

- **SiteGO · 准备开源**：将网站问答统一为 API，让账号调度、信源采集和日常运维更简单。

首批适配阿福、豆包和元宝，面向 GEO 检测与业务系统集成。目前仍在开发和验收，完成后再发布公开版本。

## 开源计划

SiteGO 是我计划长期维护的第一个开源项目。后续会继续发布解决实际问题的工具，并为已发布项目持续提供修复、文档和版本更新。

我看重清楚的文档、可复现的验证和真实反馈，也欢迎在项目公开后交流使用场景与改进建议。
